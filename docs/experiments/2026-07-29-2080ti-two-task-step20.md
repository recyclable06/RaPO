# RTX 2080 Ti 20-step two-task comparison (2026-07-29)

## Scope and status

Status: **passed** for a 20-step, two-task GRPO/RaPO comparison on the
available 8 x RTX 2080 Ti node.

This extends the five-step execution gate using the same deterministic task
order and evaluation subset. It is still not a paper result: the sequence,
image, completion, and training budgets remain reduced, and evaluation uses
only five fixed test images per class.

## Provenance and configuration

- RaPO repository commit: `d09e439`
- Visual-RFT upstream commit: `2ffad63b25ddd79bfe25d3e046645401201c89d6`
- model: Qwen2-VL-2B-Instruct, 2,208,985,600 parameters
- data: ImageNet-R order 0, Visual-RFT exports for tasks 1 and 2
- hardware: 8 x NVIDIA GeForce RTX 2080 Ti

Both methods used FP16, PyTorch SDPA, ZeRO-3 with CPU optimizer offload,
gradient accumulation 2, gradient checkpointing, 512 prompt tokens, 32
completion tokens, 100,352 image pixels, eight generations, and an initial
loss scale of 2,048. Each task ran for 20 optimizer steps from the preceding
task's final model.

## Training results

| Method | Task | Runtime (s) | Mean loss | Final gradient norm |
| --- | ---: | ---: | ---: | ---: |
| GRPO | 1 | 741.00 | 0.005732 | 0.9381 |
| GRPO | 2 | 740.29 | 0.000350 | 3.7970 |
| RaPO | 1 | 766.71 | 0.005636 | 0.5864 |
| RaPO | 2 | 738.05 | 0.000315 | 1.4342 |

All four runs completed every learning-rate transition from `9.5e-7` to zero.
No OOM, NaN, traceback, or FP16 skipped update was observed.

The task-1 RaPO state records `task_index=1`,
`normalizer.updates=38`, and
`normalizer.ema_std=0.6413358520517468`. The task-2 state records
`task_index=2`, `normalizer.updates=76`, and
`normalizer.ema_std=0.6276136770022094`.

There are 38 rather than 40 CTAN updates per task because 100 training samples
produce 13 microbatches per rank and epoch on eight GPUs. With gradient
accumulation 2, each completed epoch ends with one partial accumulation step.
Twenty optimizer steps span about 2.92 epochs and therefore 38 actual forward
passes. The state count matches the data-loader schedule exactly.

Selected task-2 RaPO retention measurements were:

| Step | Retention reward | Drift |
| ---: | ---: | ---: |
| 1 | 1.00000 | 0.00000 |
| 5 | 0.78174 | 0.02503 |
| 10 | 0.83203 | 0.02128 |
| 15 | 0.89844 | 0.00795 |
| 20 | 0.79663 | 0.01530 |

The first step starts from the frozen task-1 anchor and therefore has zero
drift. Later values vary with the sampled batch but remain nontrivial, showing
that the retention branch stays active throughout task 2.

## Bounded evaluation

Evaluation used the same fixed subset as the five-step gate: for every observed
class, the first five test images after sorting by manifest-relative path.
Generation was greedy with at most 32 new tokens. Correctness used the strict
normalized `<answer>...</answer>` matcher.

| Method | Accuracy after task 1 on task 1 | Accuracy after task 2 on task 1 | Accuracy after task 2 on task 2 | Last Accuracy | Forgetting |
| --- | ---: | ---: | ---: | ---: | ---: |
| GRPO | 94/100 | 91/100 | 99/100 | 95.0% | 3.0% |
| RaPO | 94/100 | 92/100 | 98/100 | 95.0% | 2.0% |

RaPO retained one additional old-task prediction, while GRPO produced one
additional correct new-task prediction. Their Last Accuracy is identical.
The one-sample differences are not statistically meaningful; the result
validates a longer end-to-end comparison but does not establish a method
ranking.

For reference, the five-step comparison gave 92.5% Last Accuracy and 0%
Forgetting for GRPO, versus 92.0% and 1% for RaPO. Increasing the training
budget changed both methods, so five-step and 20-step values should be treated
as separate bounded experiments rather than a monotonic learning curve.

### Expanded fixed-subset evaluation

The same 20-step checkpoints were then evaluated on 20 fixed test images per
class, giving 400 samples at stage 1 and 800 at stage 2:

| Method | Accuracy after task 1 on task 1 | Accuracy after task 2 on task 1 | Accuracy after task 2 on task 2 | Last Accuracy | Forgetting |
| --- | ---: | ---: | ---: | ---: | ---: |
| GRPO | 380/400 | 372/400 | 379/400 | 93.875% | 2.0% |
| RaPO | 380/400 | 374/400 | 379/400 | 94.125% | 1.5% |

Both methods have identical stage-1 and new-task counts. RaPO retains two
additional old-task predictions, improving Last Accuracy by 0.25 percentage
points and reducing measured forgetting by 0.5 percentage points on this
subset. This is a more stable early signal than the five-image subset, but it
still covers one class order and is not a statistical reproduction result.
